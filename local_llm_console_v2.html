Tool 1 of 2

LM Studio

GUI app. Built-in chat. No terminal needed. The one worth using.

Qwen3 32B Q4_K_M ~22 GB · ~40 tok/s
Daily start

Load and chat

  • 1
    Open LM StudioFrom Applications — it's a proper Mac app with a GUI.
  • 2
    Go to the Models tabFind Qwen3 32B in the left sidebar.
  • 3
    Click LoadWait 30–60 sec. Status turns green: "Loaded".
  • 4
    Switch to Chat tabBuilt-in chat interface — no browser, no terminal.
This is the capable one. 32B parameters at Q4_K_M quantization — noticeably better reasoning than small models.
Terminal check — optional

Verify it's serving

curl http://localhost:1234/v1/models
lms ps

Port 1234. Exposes an OpenAI-compatible API — useful later if you want to connect VS Code or other tools.

Honest assessment

What to expect

vs Llama 3.1 8BMeaningfully better. More coherent reasoning, longer context handling, fewer hallucinations.
vs Claude / GPT-4Still a gap — but usable for drafts, summaries, code review, offline research.
Your machine advantage48 GB means 32B fits with RAM to spare. Most people can't run this locally.
Best use casePrivate documents. Offline work. Things that shouldn't go to a cloud API.
Tool 2 of 2

Ollama

CLI runner. No GUI. Pair with Open WebUI for a chat interface, otherwise it's just a terminal.

llama3.1:8b 4.9 GB · fast but limited
Daily start

Start the engine + chat UI

ollama serve
  • 1
    Run ollama serveIf it says "already running" — you're good.
  • 2
    Open browser → localhost:3000That's Open WebUI — the actual chat interface.
  • 3
    Select llama3.1:8b from the dropdownTop of the chat window.
Open WebUI → localhost:3000
The raw terminal (`ollama run llama3.1:8b`) is intentionally spartan — that's the 1973 feeling. localhost:3000 is what makes it usable.
Useful commands

When things go wrong

ollama list
killall ollama && ollama serve
If Open WebUI isn't running

Start it once with Docker

docker run -d -p 3000:8080 \
-v open-webui:/app/backend/data \
--name open-webui \
ghcr.io/open-webui/open-webui:main
Run once. After that Open WebUI starts automatically with Docker.
Honest assessment

8B is the ceiling here

llama3.1:8bFast. Fine for simple Q&A and short drafts. Falls apart on nuanced reasoning.
vs Qwen3 32BNot in the same tier. If you need quality, use LM Studio instead.
What it's good forQuick offline lookups. Low-stakes drafts. Testing pipelines locally.
Could upgradePull a bigger model: ollama pull llama3.3:70b — but it'll be slower.
