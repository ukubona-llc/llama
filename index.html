Local AI Setup

Hardware: MacBook Pro M3 Max, 48 GB Unified Memory
This machine is powerful enough to run advanced local language models entirely on-device.

Step 1

Install LM Studio

↗ lmstudio.ai
  • Download the Mac (Apple Silicon) version
  • Drag into Applications
  • Launch LM Studio
  • Click "Open" if macOS shows a security prompt
Step 2

Download a Model

  • Open Discover in the sidebar
  • Search for Qwen3 32B Instruct
  • Select a quantized version

Recommended Quantization

Q2_K

Smallest — noticeable quality loss. Skip unless storage is critical.

Q4_K_M
Recommended

Best balance of quality, speed, and memory on 48 GB.

Q8_0

Near-lossless — larger than needed; no meaningful gain over Q4.

Quantization compresses model weights. Q4_K_M keeps ~95% of quality at roughly half the memory footprint of Q8. Avoid Q2 (too compressed) and Q8 (larger than necessary).
Step 3

Load the Model

  • Click Download and wait for completion
  • Click Load in the model card
  • Watch for the status indicator
Model Loaded · Ready

You now have a private ChatGPT-style system running entirely on your Mac.
