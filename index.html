🦙 Local AI Setup

Hardware: MacBook Pro M3 Max, 48GB Unified Memory

This machine is powerful enough to run advanced local language models entirely on-device.

Step 1 — Install LM Studio

Download:

https://lmstudio.ai

  • Download Mac version
  • Drag into Applications
  • Launch LM Studio
  • Click "Open" if macOS shows a security prompt

Step 2 — Download a Model

Inside LM Studio:

  • Open Discover
  • Search for Qwen3 32B Instruct
  • Select a quantized version

Recommended Quantization

Q4_K_M

This provides the best balance between:

  • Quality
  • Speed
  • Memory usage
Avoid Q2 (too compressed) and Q8 (larger than necessary).

Step 3 — Load the Model

  • Click Download
  • Wait for completion
  • Click Load

You should see something similar to:

Model Loaded
Ready

You now have a private ChatGPT-style system running entirely on your Mac.

Performance Expectations

Model Experience
Qwen3 32B Excellent
Llama 3.3 70B Possible but slower
