🚀 LM Studio Daily Guide (Offline)

For Dr. Hades - Coding Workflow in Uganda
Last updated: June 2026

1. Start LM Studio (Every Session)

  1. Open LM Studio from Applications
  2. Go to Models tab (left sidebar)
  3. Find qwen/qwen3.5-9b
  4. Click the Load button (or play icon)
  5. Wait 30–60 seconds until status = Loaded

Fan spinning up = normal

2. Quick Test (Terminal)

curl http://localhost:1234/v1/models

You should see qwen/qwen3.5-9b in the list.

3. VS Code + Continue Extension (Recommended)

  1. In VS Code → Extensions → Install "Continue" (by Continue Dev)
  2. Press Cmd + Shift + P → type "Continue: Open Config"
  3. Replace everything with this:
{
  "models": [
    {
      "title": "Local Qwen 3.5 9B",
      "model": "qwen/qwen3.5-9b",
      "provider": "openai",
      "apiBase": "http://localhost:1234/v1",
      "apiKey": "lm-studio"
    }
  ],
  "defaultModel": "Local Qwen 3.5 9B"
}

Shortcuts:
• Highlight code → Cmd + L → ask anything
• Sidebar chat for general prompts

4. Quick Commands You Need

# Load model
lms load qwen/qwen3.5-9b

# Check loaded models
lms ps

# Start chat in terminal
lms chat qwen/qwen3.5-9b

# Restart server if needed
lms server start

💡 Pro Tips

  • Close LM Studio when done to save battery & heat
  • Works completely offline after first download
  • Context is currently 4096 tokens (good for most coding)
  • For longer documents, increase context in LM Studio model settings (if RAM allows)
  • You can run multiple small models later

5. Daily Workflow (Prompt → Code)

  1. Start LM Studio + Load model
  2. Open VS Code
  3. Use Continue (Cmd+L) or the chat sidebar
  4. Write / edit code → Git → Push

You now have your own private, offline ChatGPT-level coding assistant.
